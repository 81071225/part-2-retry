# Hyath Boxing Academy Website

## 📌 Project Overview
This project is a responsive multi-page website created for **Hyath Boxing Academy (HBA)**.  
The website was developed using **HTML5** and **CSS3** and showcases the academy’s information, services, contact details, and enquiry features.

The website follows responsive web design principles to ensure compatibility across:
- Mobile devices 📱
- Tablets 📲
- Desktop screens 💻
